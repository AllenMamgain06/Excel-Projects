# 📊 Advanced Excel Data Analysis & Dashboards

Welcome to my Excel Projects portfolio! This repository features interactive business dashboards built to process raw datasets, analyze Key Performance Indicators (KPIs), and present visual business insights.
💳 1. UPI Transactions Analytics Dashboard
📌 Project Overview
Analyzed large transaction datasets to evaluate payment stability, fraud patterns, and monetary volume distribution across regions.

🖼️ Dashboard Preview
🔑 Key Features & Technical Details
Payment Performance: Tracked overall Success Rate (91.00%), Total Transactions (5,02,887), and Net Amount (₹ 44.25 Cr).

Risk Analysis: Mapped suspected fraud cases (17,089 transactions) using conditional metrics.

Financial Rewards: Monitored Cashback disbursement trends (₹ 34.63 L).

Interactivity: Integrated dynamic Slicers and Filter Panels for instant regional breakdowns.

Formulas & Tools: SUMIFS, COUNTIFS, Pivot Tables, Dynamic Charts, and Conditional Formatting.
